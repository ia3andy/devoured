Direct from the API

Set the model header to drama-3 and send your script as it is. Directions, sounds, and paired tags all work in API requests.

curl https://api.fish.audio/v1/tts \
  -H "Authorization: Bearer $FISH_API_KEY" \
  -H "Content-Type: application/json" \
  -H "model: drama-3" \
  -d '\{
    "text": "I’m fine. Really. <whisper>Go on without me.</whisper>",
    "reference_id": "f3a2b90078d54a65af4b95f63bc7798e"
  }' --output speech.mp3

Drama 3 FAQ

What is Drama 3?

Drama 3 is a text-to-speech model from Fish Audio built for direction. Alongside your script you can describe how a line should be performed, add sounds and pauses, and limit an effect to specific words.

How do I write directions?

Put a direction or a sound in square brackets where it should happen, for example [sigh] or [barely holding it together]. To change only some words, select them and pick a scoped tag such as Whisper or Slower from the Tags menu; the editor wraps them in a paired tag.

Can I write directions in other languages?

Yes. Write tags and directions in English or your own language.

Does Drama 3 support multiple speakers?

Yes. Add speakers in the Text to Speech editor, give each one a voice, and Drama 3 generates the whole dialogue together.

What does Preview mean?

Drama 3 is still improving. Results vary between takes, so generate a few and pick the best. We will keep updating the model while it is in preview.

Can I use Drama 3 through the API?

Yes. Call the Text to Speech API with the model header set to drama-3. The same tags work in API requests.
