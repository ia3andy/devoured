API version 2026-10-21 is now available.

The Claude API has evolved a lot, but this is our first official version release since 2023. We plan to release versions more often so you can handle breaking changes before a new model requires them.

2023-06-01 is not deprecated. What changes in this version:

  • temperature, top_p, and top_k are removed from the Messages API
  • documents in assistant turns and citations in user turns return a 400
  • a few deprecated Admin and Enterprise Analytics API fields are replaced

New major versions of the Anthropic SDKs and the ant CLI are out today and default to 2026-10-21.

You can use the /claude-api skill in Claude Code to update, or walk through each change in the migration guide: platform.claude.com/docs/en/api/migration-2026-10-21
