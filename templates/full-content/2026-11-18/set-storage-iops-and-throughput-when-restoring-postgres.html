Set storage IOPS and throughput when restoring Postgres backups

Postgres backup restores will now let you set storage IOPS and throughput for the new branch. Large restores are often limited by disk throughput, so this lets you speed up a restore without choosing a bigger cluster size than the branch needs.

You'll find the new settings in the Restore to new branch dialog for branches on AWS network-attached storage. The settings stay on the restored branch, and you can change them later from its storage settings.

You can also set them from the CLI with --storage-iops and --storage-throughput:

pscale backup restore <DATABASE_NAME> <NEW_BRANCH_NAME> <BACKUP_ID> \
  --storage-iops 5000 --storage-throughput 300

Through the API, set storage_iops and storage_throughput_mibs in the storage object when you create a branch from a backup or a point in time.
