SALT LAKE CITY -- Solo.io announced at KubeCon + CloudNativeCon North America 2026 the general availability of its enterprise releases of Agent Substrate and kagent. Agent Substrate provides an infrastructure layer for agentic runtimes that combines serverless scale, sandbox isolation and governed connectivity, while kagent adds the developer experience for building and managing agents, tools and skills. Launch customers OutSystems and Swissquote are already running the stack in production.

Agent Substrate is built around the idea that a dedicated pod for every agent session ties up resources while agents wait on models, tools or human input. Its execution model suspends idle sessions and resumes them on demand, so enterprises can scale agents on the Kubernetes infrastructure they already operate. The project introduces the actor as the basic runtime unit for agents, pairing each agent session with a sandbox that isolates execution and a gateway that governs who can reach it and what it can access. State, identity and access controls stay with the actor as the compute underneath changes.

Enterprise Distributions Add Gateway Controls and Tracing

Solo’s enterprise distributions use agentgateway as the actor’s gateway, enforcing identity and policy controls on ingress and egress traffic. kagent adds granular access control, agent tracing, infrastructure monitoring and evaluations built from real execution traces. Enterprise support and deployment options, including air-gapped installations, are also available. Solo co-maintains Agent Substrate with Google, and the community’s Agent Substrate 1.0 release follows six months of development with more than 6,000 GitHub stars and over 100 contributors from more than 40 organizations. Solo has also published a sizing calculator on the kagent project site to help teams size environments and set service-level objectives.

“The next generation of applications will be agents. The infrastructure they need is being defined right now, and the choices we make will shape how enterprises run for years to come,” said Idit Levine, founder and CEO of Solo.io. “We’re building for a world where agents carry out work across every part of an organization, with isolation and control built into the infrastructure from the start.”
