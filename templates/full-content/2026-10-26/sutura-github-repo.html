sutura

sutura is a semantic data runtime written in Rust. It serves queries over HTTP and MCP. By default, queries use certified metric definitions. Metadata and data sources connect through adapters. A query can combine data from several sources.

Deployments can verify caller tokens. Each data source declares the identity it uses. See identity verification for each identity claim and its environment.

Technology

  • Apache DataFusion executes local queries.
  • Apache Arrow carries result batches inside the runtime.
  • ADBC connects to data systems.
  • polyglot-sql renders SQL for each dialect.
  • Wren and Spice provide design references for semantic models and query federation.

See architecture and integrations for details.
