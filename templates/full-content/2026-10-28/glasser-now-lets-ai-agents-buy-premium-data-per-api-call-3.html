Glasser is a data service that lets AI agents buy premium data one call at a time. A single key opens more than 2,000 paid API endpoints from over 80 providers, from company records and SEO metrics to social media and financial filings.

Most of these sources normally sit behind their own monthly plans. Glasser’s pricing page lists Ahrefs Lite at $129 a month, Semrush at $139 a month before API access, and Apollo at $65 per seat each month. A team that needs a few keyword checks and some company lookups each week still pays full price for each one.

Setup takes one prompt. Users paste a one-line setup instruction from Glasser’s site into an agent such as Claude Code, Codex, or Cursor, and the agent installs the Glasser command-line tool and opens a browser sign-in. From then on, the agent finds a data source that fits the task, checks the call cost, runs it, and reports the charge along with a link to the provider’s raw answer.

On Glasser, Ahrefs organic keyword data is listed at $0.055 per call, Semrush keyword metrics at $0.0011, and an Apollo company search at $0.026. At those prices, an Apollo seat becomes cheaper only after about 2,500 company searches a month, and the Ahrefs Lite plan after about 2,300 keyword calls. Below those volumes, paying per call costs less.

Each endpoint shows its billing rules before it runs, and some charge nothing when a search comes back empty. Glasser’s instructions tell agents to name the price and wait for approval before any bulk or repeated paid calls, and to use a provider key the user already owns whenever one exists.

Glasser also keeps an open-source skills library on GitHub. Its recipes turn a request such as a competitor brief or an SEO audit into the right sequence of paid calls, and the catalog picks the provider, so a skill keeps working when a source changes.

TestingCatalog ran a test on Perplexity’s domain through Glasser’s connector in Claude. A Hunter company lookup came back in under two seconds with a headcount of 1,366, $1.46 billion in recorded funding, and 73 detected technologies, for $0.0049. A 10-row Semrush keyword report followed for $0.0055, showing the brand name at position one with 1.5 million monthly US searches and the Comet browser page ranking first for its own name. The same company lookup is listed at $0.026 from Apollo, $0.10 from People Data Labs, and $0.66 from Crustdata, and the agent picks whichever provider fits the task.

Glasser works with local agents including Claude Code, Codex, Cursor, Gemini CLI, OpenClaw, and Hermes, while hosted assistants such as Claude on the web connect through an MCP connector. New workspaces start with $1 in free credit, and users can add more funds in the Glasser console.

Glasser is built by Super Intent, Inc. According to its documentation, new endpoints and providers are added to the catalog every week.
