The Logo.dev MCP server gives AI agents the Logo.dev API as tools. Your agent can look up a brand by domain, ticker, ISIN, crypto symbol, or name, fetch its logo or brandmark, search brands, and manage webhook subscriptions.

https://mcp.logo.dev/mcp

Transport and sign-in

The server uses the streamable HTTP transport and signs you in with OAuth. The first time you connect, your MCP client opens a browser window where you sign in to Logo.dev. You don’t put a secret key in the client’s configuration. Each tool runs as, and bills to, your team. If you have no team, it runs as your personal account. You don’t need to create an API key for MCP. Each tool has the same access checks, rate limits, and webhook subscription behavior as the REST route it mirrors. Tool calls count as MCP usage, which spends API credits at the same rates as REST requests.
