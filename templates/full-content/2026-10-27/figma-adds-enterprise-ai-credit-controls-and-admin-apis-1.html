Figma is rolling out new Enterprise admin controls for paid AI credits, account management and workspace automation.

Shared defaults, individual exceptions

Admins can set default paid-credit access for each user across an organization or billing group. Options include a monthly limit, full access or no access to paid credits. Existing custom user settings take priority, while a billing group’s default overrides the organization’s default.

These controls apply to purchased credits, not the credits included with a person’s seat. A personal limit does not reserve credits: shared pools can run out first.

The settings dialog shows how many people a change will affect before it is saved, including those whose custom limits will remain unchanged. For DesignOps teams, this makes the scope of a bulk change visible before applying it.

Account provisioning and admin APIs

Teams using SCIM, a standard for automatically managing user accounts, can configure paid-credit access through their identity provider. When a limit is managed this way, admins can view it in Figma but must change it in the identity provider.

The release also lets Enterprise admins prevent employees from creating new Starter or Professional plans with company email addresses. New admin REST APIs support managing teams, folders and files.
