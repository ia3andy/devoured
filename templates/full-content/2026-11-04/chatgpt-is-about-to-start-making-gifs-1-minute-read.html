ChatGPT is about to start making GIFs. OpenAI just merged animated GIF output into its image generation, already live in the Codex code behind a new flag called image_generation_animation. You pick the frame count and the duration of each frame, and you can even turn spritesheets into animated GIFs. The animation is generated by OpenAI's Images API itself, not by Codex, which means this is coming to ChatGPT too. Static images are about to feel old.
