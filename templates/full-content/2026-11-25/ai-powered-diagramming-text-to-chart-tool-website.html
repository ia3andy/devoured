FAQ

What is Mermaid?

Mermaid is a collaborative diagramming platform that lets you create diagrams using AI, code, or clicks. Upload a doc to generate diagrams automatically, build flowcharts and sequence diagrams with Mermaid syntax, or use the visual editor — all in one place.

What's the difference between Mermaid.js and Mermaid?

Mermaid.js is the free, open-source diagramming library that powers text-to-diagram rendering. Mermaid is built on top of it, adding AI-powered generation, file uploads, a visual editor, real-time collaboration, team workspaces, plugins, and enterprise support. It was created by the team behind Mermaid.js to bring professional tooling to the Mermaid ecosystem.

Why use Mermaid instead of other diagramming tools?

Mermaid offers several key advantages: diagrams are text-based and live alongside your code, making them easy to version control and integrate into your development workflow. You can generate diagrams from docs and transcripts with AI, collaborate in real time, share with a single link (no login needed), and work directly inside the tools your team already uses.

How do I create a diagram?

Six ways, and you can mix them: chat with AI, prompt inline right on the canvas, speak your edits with voice, start from a template, write Mermaid syntax, or drag and click in the visual editor. Use one or use all of them — whatever fits how you're thinking.

Can I upload files to generate diagrams?

Yes. Upload meeting transcripts, PRDs, PDFs, screenshots, or code snippets directly to Mermaid AI. Each conversation retains context across your uploads, so you can iterate as the project evolves without starting from scratch.

Does Mermaid work with AI tools like Claude?

Yes. Our MCP (Model Context Protocol) server lets you generate, validate, and render Mermaid diagrams directly from Claude, VS Code, Cursor, and other AI-native tools — no manual syntax wrangling. Developers can also connect to our remote MCP server to automate diagram generation in their own workflows.

Do I need to know code to use Mermaid?

Not at all. While Mermaid uses text-based syntax, it's simple and intuitive to learn. Plus, you've got a visual drag-and-drop editor and an AI assistant that generates diagrams from natural language – so you can create diagrams however you're most comfortable.

How do I get started?

Sign up for a free account and create your first diagram using the visual editor, AI assistant, or by writing Mermaid syntax directly. You can also try uploading a doc or transcript to see AI in action right away.

Is Mermaid free to use?

Yes. Mermaid offers a Basic plan with core diagramming features. Paid plans include advanced collaboration tools, increased AI credits, and file upload capabilities. Need SSO, custom contracts, or dedicated support? Our Enterprise plan has you covered.

Do you have plugins?

We integrate with the tools you already use: ChatGPT, GitHub Copilot, Confluence, Jira, Visual Studio Code, JetBrains IDEs, Google Docs, and more. We also support AI-native workflows via our MCP server for Claude, Cursor, and VS Code.

Do you have an Enterprise tier?

Yes. The Enterprise plan includes single sign-on (SSO), custom integrations, dedicated support, and more for larger organizations.
