GitHub began rolling out a redesigned pull request Overview page on November 5 as an opt-in public preview. Availability will continue expanding through the weekend.

A compact summary at the top shows whether the change is ready to merge, what is blocking it and which actions are available. Checks, approvals and comments remain accessible from that summary.

The conversation also gains filters for unresolved threads and the user’s own comments, newest-first sorting, and a recent-activity summary. Depending on permissions, users can mark a draft ready for review or close a pull request from the header.

The design addresses a navigation problem in long discussions: finding the current state no longer requires scrolling to the merge box below the conversation. Users can start with the blocking issue and open its supporting details.

The preview can be enabled through the Try the Overview page button in the header. The same menu allows a return to the classic view. GitHub describes this as an early iteration rather than the completed redesign.
