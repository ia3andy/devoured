Using Argo CD and Kargo, Meta is building a GitOps platform to streamline application delivery across 100 Kubernetes clusters supporting AI research and inference

Key Highlights

  • Meta’s Cloud Foundation team won the CNCF End User Case Study Contest for its GitOps platform, built with Argo CD and Kargo to streamline Kubernetes application delivery.
  • The new platform cuts routine application deployment times from more than four hours to minutes, streamlining the small team’s workflow through a simplified application definition while adding more advanced features such as automated deployment configuration, independent release promotion, and health verification.
  • By separating application delivery from infrastructure provisioning, Meta is enabling independent application rollouts while retaining Terraform for infrastructure management.

SALT LAKE CITY – KubeCon + CloudNativeCon North America 2026 – November 10, 2026 – The Cloud Native Computing Foundation® (CNCF®), which builds sustainable ecosystems for cloud native software, announced Meta as the winner of the CNCF End User Case Study Contest for its adoption of cloud native technologies to accelerate application delivery across its AI infrastructure. Through a GitOps platform built on Argo CD and Kargo, Meta’s Cloud Foundation team is transforming how applications are deployed and managed across approximately 100 Kubernetes clusters supporting AI research and inference, reducing routine deployment times from more than four hours to minutes.

“AI infrastructure is causing organizations to rethink how they manage applications across distributed environments,” said Chris Aniszczyk, CTO, CNCF. “Meta’s approach demonstrates how open source technologies like Argo can help teams automate their application delivery, reduce operational complexity and scale infrastructure without adding unnecessary overhead. It’s a powerful example of how cloud native technologies are supporting the operational demands of AI at scale.”

Meta’s Cloud Foundation team, composed of more than 15 engineers, supports approximately 100 Kubernetes clusters across multiple cloud providers and accelerator families. Previously, Terraform was used for both infrastructure provisioning and Kubernetes application deployment, tying even routine application updates to a lengthy infrastructure release process. The shared deployment model meant stalled rollouts could delay unrelated releases and lacked automated health checks to verify application status.

To address these challenges, Meta began building a GitOps platform that separates application delivery from infrastructure provisioning. Terraform continues to manage infrastructure, while Argo CD reconciles application deployments against configurations stored in Git. Kargo orchestrates release promotion across environments, enabling independent rollouts, automated health checks and versioned release records that improve deployment traceability and recovery.

“GitOps and Argo CD give our small team a great foundation, shaped by years of community experience in Kubernetes delivery,” said Phong Nguyen, Production Engineer, Meta. “We focus on connecting it to Meta’s systems and aim to share our own lessons along the way.”

Meta also simplified application delivery by allowing developers to specify deployment requirements through a short application definition. The platform automatically generates Argo CD and Kargo configurations, enabling independent release promotion, automated health verification and deployment consistency without requiring application teams to manage complex configurations.

Meta plans to expand adoption of its GitOps platform and transition to a centrally managed Argo CD service to reduce maintenance overhead across its Kubernetes fleet. The team is also exploring upstream contributions to improve container registry authentication and Argo CD performance in large clusters.
