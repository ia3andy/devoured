GitHub Agentic Workflows, an open source project from GitHub Next, is now generally available. With agentic workflows, you can automate reasoning-based tasks like issue triage, CI failure analysis, documentation updates, and test writing by using coding agents inside GitHub Actions.

Define your automation in natural language Markdown files, and GitHub Agentic Workflows compiles them into standard Actions YAML. Because these are GitHub Actions, they reuse your existing runner groups and policy constraints. You can use GitHub Copilot or bring your own coding agent to power each workflow.

Built-in safeguards

GitHub Agentic Workflows incorporates layered safeguards for your automation. Agents access GitHub content respecting the integrity filter rules, run with read-only permissions by default, and execute inside a sandboxed container behind the Agent Workflow Firewall. The outputs are validated through the safe outputs process, and a dedicated threat detection job scans all proposed changes before they are applied.

Additional capabilities for general availability

Highlights since the public preview include:

  • Actions Runner Controller (ARC) and Docker-in-Docker support: Run agentic workflows on self-hosted ARC runners with Docker-in-Docker.
  • Improved budget forecasting: gh aw forecast is no longer experimental. It now includes both threat detection credits and monthly ranges for a fuller picture of your AI credit spend.
  • New models, engine choices, and workflows: The model inventory has been refreshed, model providers can be picked per workflow, and there are new workflow templates that can be added with gh aw add-wizard.
  • Model routing: Workflows can use a model router that optimizes for task type and difficulty.
  • Improved agent isolation: Agents can run in a Cloud Hypervisor or NVX micro-VM and prevent data leaks in cross-repository workflows with enclaves.

See the GitHub Agentic Workflows release notes for the full list of changes.

Get started

Follow the quickstart guide to install the CLI extension and trigger your first workflow in minutes. Explore prebuilt workflows in GitHub Next’s agentics repository for ready-to-use examples covering triage, dependency management, code review, and reporting.
