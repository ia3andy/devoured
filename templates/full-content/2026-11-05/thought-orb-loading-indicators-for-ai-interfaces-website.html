SwiftUI

Installation

// Package.swift — or Xcode: File › Add Package Dependencies… › paste the URL (Branch: main)
.package(url: "https://github.com/Jakubantalik/Libraries.dev", branch: "main")
// …and in your target's dependencies:
.product(name: "ThinkingOrbsKit", package: "Libraries.dev")

Usage

import ThinkingOrbsKit

ThinkingOrb(state: .searching, size: .px64)

Orb replaces the spinner in an AI "thinking" state with nine hand-tuned animated states. It ships zero runtime dependencies and needs React 18 or newer.

Props

  • state: "working" | "searching" | "solving" | "listening" | "connecting" | "weaving" | "composing" | "breathing" | "shaping"
  • size: 64 (chat-avatar scale) or 20 (inline-text scale) — each is separately tuned
  • speed: multiplies the animation clock, default 1
  • dark: boolean, picks the light or dark tuning
  • paused: boolean, freezes the animation
